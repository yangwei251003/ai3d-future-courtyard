# Gates and Recovery

| Gate | Required evidence |
| --- | --- |
| G0 | Tool versions, paths, ports, Blender/Godot MCP health |
| G1 | Five modules, ten props, character blockout, fixed views |
| G2 | Final geometry, naming, origins, transforms, collision/navigation proxies |
| G3 | Palette, day/night review, rig and four animation clips |
| G4 | glTF validation, budget checks, clean re-import, CAD Viewer review |
| G5 | Godot import, headless checks, movement/collision/animation/navigation runtime |
| G6 | Web build, desktop/mobile interactions, fallback, zero console errors |
| G7 | Cross-consumer hashes, manifest, screenshots, video, documentation |

On first failure, fix only the current stage script. On a repeated equivalent failure, restore the prior approved checkpoint and isolate one variable. Never promote a failing candidate or overwrite the prior canonical GLB.
