# 学习挑战：真正走完一次

完成后在每项后面打勾；在你亲手做完前，本教程不会把“已掌握”写进任何验收结果。

- [ ] 双击启动完整演示，在 Godot 中走、跑、跳、撞墙并切换昼夜。
- [ ] 在 Web 中切换四段动画、配色和昼夜；用手机宽度查看静态降级。
- [ ] 修改 brief 的 accent 色，重建后确认 Godot、Web、CAD 三端一起变化。
- [ ] 缺动画 fixture：临时改错 `Jump` 名称，观察 G3/G4 失败，再恢复。
- [ ] 哈希漂移 fixture：复制一份 runtime GLB 到临时目录并改一个字节，观察哈希门禁失败；不要修改规范资产。
- [ ] 尺度 fixture：在候选脚本分支把一个道具放大 100 倍，观察边界/视觉验收失败，然后回到 geometry 检查点。
- [ ] 用《如何描述下一个3D任务》的示例生成 12×12 米月光小庭院。
- [ ] 不看文档，用自己的话解释：为什么候选不能直接覆盖 runtime？为什么 Godot/Web 不补根旋转？manifest 的哈希解决了什么问题？

能独立回答最后三问，并从失败检查点恢复一次，才算掌握这套流程。
