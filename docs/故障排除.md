# 故障排除

## Blender MCP 无法连接

先打开 Blender，确认侧栏 Blender MCP 显示服务器运行，且只有一个进程占用 `localhost:9876`。运行 `tools/doctor.ps1`。本项目固定 `blender-mcp==1.9.0`、uv 管理的 Python 3.11，并关闭遥测。`get_scene_info` 必须传 `user_prompt`。不要同时启用旧插件。

如果干净重启后同一故障连续复现两次，先备份当前插件，再考虑文档中记录的 newo-ether v1.17.0 回退；不要安装旧 webita 分支。

## Godot MCP 能读项目但不能运行

项目固定 Godot 4.7.2 和 `godot-mcp-runtime@3.2.2`。`.codex/config.toml` 已设置精确 `GODOT_PATH`、严格模式及无人值守运行所需的关闭提示变量。新加 MCP 后必须开一个全新的 Codex 任务，旧任务不会可靠热加载。

若运行态附加失败，先用 `game/tests/smoke_test.gd` 做无界面检查，再确认 `.mcp` 审计记录；严格模式只是静态防线，不是操作系统沙箱。

## Web 黑屏或一直显示“载入规范 GLB”

先运行 `npm --prefix web run build`，再运行 `npm --prefix web run test:e2e`。Web 预览固定使用 4188 端口；4173 在本机出现过绑定拒绝，因此不使用。强制静态降级可访问 `http://127.0.0.1:4188/?forceFallback=1`。

## 模型尺度或朝向错误

Blender 里 1 单位=1 米、Z-up、角色面向 -Y；导出后是 glTF Y-up/+Z 正面。Godot 和 Web 禁止再补根缩放或根旋转。检查模块原点是否位于地面中心，角色根节点是否在脚底，可见网格是否存在负缩放。

## 动画丢失

GLB 中必须保留 `Idle_loop`、`Walk_loop`、`Run_loop`、`Jump`。Godot 导入器可能显示为 Idle/Walk/Run，控制器已做别名映射。若 manifest 缺少任一原名，候选资产不得提升。

## 哈希漂移

运行 `tools/validate_assets.py` 和 `tools/verify-all.ps1`。不要手工把候选 GLB 复制到 `assets/runtime`；只有 `--promote` 在门禁通过后可以更新规范资产与 manifest。
