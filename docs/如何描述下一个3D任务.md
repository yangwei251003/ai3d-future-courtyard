# 如何描述下一个 3D 任务

把下面模板复制给 Codex，并尽量给出数值。清楚的预算比“做精致一点”更容易得到稳定、可复现的结果。

```text
请基于本仓库的 3d-production-pipeline 新建资产：
- assetId：
- 用途：Godot / Web / CAD / 渲染
- 场地尺寸与单位：
- 视觉风格与色板：
- 必须出现的模块、道具、角色：
- 角色动画名称与速度：
- 三角面、材质、纹理、文件大小预算：
- 交互：移动、相机、碰撞、导航、昼夜等
- 目标设备：桌面 / 手机 / 集显
- 验收截图角度：
- 禁止项：外部纹理、扩展压缩、云服务等
请先写 brief 和验收合同；按检查点构建；候选通过门禁后才提升；Godot、Web、CAD 使用同一份 runtime GLB；输出证据、视频、manifest 和中文使用说明。
```

## 第二个小庭院示例

复制 brief，把 `assetId` 改为 `moon_garden`，seed 改为 84，场地改为 12×12 米；保留五类模块中的墙、门、柱，只放长椅、灯、树、无人机台四类道具。预算设为 8,000 三角面、5 材质、1 MiB、0 纹理。先做静态环境，不要角色。这样可以验证工作流是否真正可复用，而不是只会重放第一个项目。
